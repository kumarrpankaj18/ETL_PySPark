During this project, I leveraged the <b>Finnhub API</b> to fetch real-time and historical stock data for companies like Apple, Microsoft, and Google.<br>I extracted and transformed data from endpoints such as stock quotes, financial metrics, insider sentiment, and EPS surprise.</br><br>Using PySpark, I handled data at scale and wrote outputs into CSVs (using coalesce for single-file output).</br><br> I also visualized trends using Seaborn—including line plots, bar charts, and histograms—while understanding the differences between Spark and Pandas DataFrames.</br>I also addressed common challenges like nested JSON parsing, API limitations, and merging disparate data sources
